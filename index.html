Share anonymous usage stats? Off by default. If you turn this on, Unicorn sends a tiny anonymous record each time you generate replies — which voice + model you used, how many options came back, which one you copied, how long it took, and the app version. It never sends your screenshots, the conversation, the reply text, or your API key — only counts and timings. It helps the user see what's working for the circle. Turn it off any time to stop.
